# Python data structures practice

Small exercises for revisiting stacks, queues, and deques. A place to get the basics wrong, then less wrong.

## Explore

Open `stacks.py`, `queues.py`, or `deque.py` to read an exercise.
Run a file with Python 3 from the repository directory:

```sh
python stacks.py
```

These are study notes and experiments, not a packaged library.
